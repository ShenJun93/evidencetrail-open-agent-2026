## Product state

EvidenceTrail now shows a visual source-to-claim Evidence Map, selectable source-removal previews, strict abstention, bounded joint-dependency search, and reviewable typed-case updates. The main Milton example separates NOAA wind speed from Florida county-count claims. The warehouse case is fictional. The product is research-only, not an operational service.

The latest local judge replay passed 580 Python tests, 20 chronology checks, six Edge scenarios and the WHY Evidence Map interaction. It ran on a dirty worktree with `.env.local` and the Meterless vendor checkout present. The runner reports no key-file read or sponsor request, but this is not a clean keyless source replay or an independent user evaluation. Human impact is unmeasured (n=0).
