Evidence guardrails

Every record, including future records, is checked against source identity and a declared manifest before interventions. Strict mode abstains without independent historical availability proof. Fictional sources are never independent corroboration. The default route reads static fixtures; case import processes submitted JSON locally. No model request occurs unless you separately enable the local Nightshift route and confirm a case-level request below. This route sends only selected before/after claim facts to loopback; it cannot invoke Zetaris or NVIDIA.

      Ask the local model to explain this change

      EvidenceTrail computes the claim first. With the server opt-in enabled, this sends only the selected claim key, before/after values and source IDs to the local Nightshift Runtime. No URL, full case, cloud provider, SQL query or source collection is sent. The model cannot change the computed result.

      Checking local feature availability…

      The response is unverified model prose. Any displayed route name is runtime-reported, not independently attested. A browser case request is still separate from Zetaris/H-MEM or NVIDIA sponsor proof.

      Source withdrawal is a counterfactual, not a causal claim about real-world events or publisher retractions. No model request occurs in offline replay; the optional local Runtime request requires a separate server flag, checkbox and button click. No participant study is performed.
